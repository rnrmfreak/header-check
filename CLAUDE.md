\# Project: header-check

CLI Python untuk mengecek security header HTTP.



\## Aturan

\- Python 3.11+, dependency seminimal mungkin (requests, pytest).

\- Semua kode di folder src/, test di tests/.

\- Test TIDAK boleh melakukan request jaringan sungguhan; gunakan mock.

\- Jangan hardcode credential atau token apa pun.

\- Jalankan `pytest` sebelum menyatakan tugas selesai.
